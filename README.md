## Penjelasan Program

Program Aplikasi Prediksi Prodi Pilihan dibuat menggunakan bahasa pemrograman Python dengan library Tkinter untuk membuat tampilan GUI (*Graphical User Interface*). 
Aplikasi ini memiliki satu label judul, 10 input nilai mata pelajaran, satu tombol **Hasil Prediksi**, dan satu label untuk menampilkan hasil.

Pengguna dapat memasukkan nilai pada setiap kolom yang tersedia, kemudian menekan tombol Hasil Prediksi untuk menampilkan program studi **Teknologi Informasi**. 
Hasil tersebut akan tetap sama apa pun nilai yang dimasukkan karena program ini menggunakan fungsi prediksi sederhana yang tidak melakukan perhitungan nilai.

Dalam program ini, `Label` digunakan untuk menampilkan teks, `Entry` untuk menerima input, `Button` untuk menjalankan fungsi, dan `mainloop()` untuk menjalankan tampilan aplikasi agar tetap terbuka. 
Tata letak komponen diatur menggunakan `pack()` dan `grid()`, sedangkan font Times New Roman digunakan agar tampilan lebih rapi.
